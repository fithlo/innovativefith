# AI-Powered Smart Habit Tracker
A lightweight, intelligent application designed to help users build sustainable daily routines using adaptive AI suggestions.

## Overview
Smart Habit Tracker is a developer productivity assistant that logs daily habits, analyzes consistency patterns, and leverages AI to generate personalized motivational insights and weekly feedback. 

##  Key Features
- **Habit Tracking:** Log habits directly and monitor daily consistency.
- **AI-Powered Insights:** Automatically generates summary tips based on your completion rates.
- **Streak Analytics:** Calculates current streaks, longest streaks, and completion percentages.
- **Clean UI:** Simple, developer-friendly interface.

## 🛠️ Tech Stack
- **Frontend/CLI:** Node.js, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **AI Integration:** OpenAI API

## 📦 Getting Started

### Prerequisites
- Node.js (v18.0 or higher)
- npm or yarn

### Installation
1. Clone the repository:
   
```bash
   git clone [https://github.com/your-username/smart-habit-tracker.git](https://github.com/your-username/smart-habit-tracker.git)
   cd smart-habit-tracker
   

 * Install dependencies:
   npm install
   

 * Set up environment variables:
   Create a .env file in the root directory:
   PORT=3000
   OPENAI_API_KEY=your_openai_api_key_here
   

 * Run the application:
   npm start
